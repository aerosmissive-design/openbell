# 오픈벨 나스(풀로컬) — 쉬운 설명

베셀(클라우드)은 **다른 사람/알림용**으로 두고,
**집 나스에서만** 감시 + (나중에) 좌석 선점까지 돌리는 방식입니다.

---

## 한 줄로

> 집 컴퓨터(나스) 하나가 **감시도 하고, 자리 잡기도 한다.**
> 결제는 절대 안 하고, 결제 화면까지만 가서 **내가 직접 결제**한다.

---

## 무엇이 돌아가나 (그림)

```
[나스 DS423+ 또는 DS225+]

  ① 오픈벨 앱 (웹)
     · 영화/극장 감시
     · 잔여석 확인
     · 텔레그램·메일 알림

  ② 예매 도우미 (나중에 추가)
     · 알림 뜨면 브라우저로 회차 들어가기
     · 선호 좌석 클릭
     · 결제 페이지에서 멈춤  ← 여기까지
     · 결제 버튼은 안 누름

[내 폰/PC]
  · 알림 보고 결제만 하면 끝
```

베셀 서버는 **안 써도 됩니다.** (풀로컬 = 집 안에서 끝)

---

## 두 나스 어떻게?

| 나스 | 하는 일 |
|------|--------|
| **DS423+** (추천 메인) | 오픈벨 + 예매 도우미 전부 |
| **DS225+** | 나중에 백업, 또는 한쪽만 감시 |

처음에는 **423+ 한 대만** 켜도 됩니다.
둘 다 같은 계정으로 동시에 자리 잡으면 서로 싸울 수 있어서,
**자리 잡기는 한 대만** 하게 하세요.

RAM: 예매 도우미(브라우저) 쓸 거면 **6GB 근처**가 편합니다.

---

## 단계 (쉬운 순서)

### 1단계 — 나스에 오픈벨만 띄우기 (지금 목표)

1. 나스 DSM에서 **Container Manager**(도커) 설치
2. 이 폴더(`nas/`)의 `docker-compose.yml` 사용
3. 브라우저에서 `http://나스IP:3080` 접속
4. 예전에 베셀에서 쓰던 것처럼 감시·알림 설정

→ 여기까지면 **집 안에서 감시·알림**이 됩니다.
→ CGV가 클라우드에서 막히던 것도, 집 회선에서는 나을 수 있습니다.

### 2단계 — 예매 도우미 (나중에)

- “알림 뜨면 좌석까지 찍어 주고 직전에서 멈춤”
- 캡차 나오면 **즉시 중단**하고 나한테 알림
- **결제 버튼은 코드에 넣지 않음**

2단계는 1단계가 안정된 다음에 붙입니다.

## 어려운 말 번역

| 어려운 말 | 쉬운 말 |
|-----------|--------|
| 풀로컬 | 전부 집에서 돌림 |
| 워커 | 예매 도와주는 프로그램 |
| Docker / 컨테이너 | 나스에 앱을 상자처럼 넣어 실행 |
| compose | 그 상자를 켜고 끄는 설명서 파일 |
| job | “이 영화 이 좌석 잡아줘” 한 건의 요청 |
| 모노레포 | 알림 앱이랑 예매 도우미 코드를 한 저장소에 같이 둠 (지금은 몰라도 됨) |

---

## 절대 안 하는 것

- 결제 버튼 자동 클릭
- 캡차 우회
- 카드/간편결제 자동 입력
