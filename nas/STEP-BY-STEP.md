# 나스에서 오픈벨 켜기 (초보용 순서)

기기: **DS423+(메인 추천)** 또는 DS225+

---

## 준비물

1. 나스가 켜져 있고, 같은 와이파이/랜에 폰·PC가 있음
2. DSM 관리자 로그인 가능
3. 나스 RAM이 빠듯하면 (2GB) → 웹만 먼저, 예매 도우미는 RAM 늘린 뒤

---

## 1. Container Manager 설치

1. DSM 열기
2. **패키지 센터**
3. **Container Manager** 검색 → 설치
4. 열어서 한 번 실행

---

## 2. 코드 받아 두기

쉬운 방법 하나:

1. PC에서 https://github.com/aerosmissive-design/openbell 접속
2. Code → Download ZIP
3. 압축 풀기
4. 나스 **File Station**으로 `openbell` 폴더 통째로 업로드
   (예: `docker/openbell/`)

---

## 3. 프로젝트 실행

1. Container Manager → **프로젝트**
2. **생성**
3. 경로: 방금 올린 폴더 안의 `nas` 또는 저장소 루트 (compose 파일 위치)
4. `docker-compose.yml` 이 보이면 그대로 생성·시작

> Dockerfile 이 아직 없거나 빌드가 실패하면
> “빌드 에러 로그”를 복사해서 알려 주세요.
> 그때 나스에 맞는 Dockerfile 을 맞춰 드리겠습니다.

---

## 4. 접속

PC/폰 브라우저 주소창:

```
http://나스IP주소:3080
```

나스 IP는 DSM → 제어판 → 네트워크 에 나옵니다.
예: `http://192.168.0.50:3080`

---

## 5. 알림 설정

베셀에서 쓰던 것과 같습니다.

- 텔레그램 토큰·채팅 ID
- 메일 등

집 나스에서 감시하므로, **베셀 없이도** 알림이 옵니다.

---

## 아직 안 하는 것 (2단계)

- 좌석 자동 클릭
- 결제 페이지 자동 이동

1단계(감시·알림)가 잘 되면 그때 “예매 도우미”를 붙입니다.

---

## 막힐 때 보낼 것

1. 나스 기종 (423+ / 225+)
2. RAM 용량
3. Container Manager 빨간 에러 글자 전체
4. 접속 주소로 뭐가 보이는지 (안 열림 / 흰 화면 / 로그인 등)
