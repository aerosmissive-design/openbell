# 오픈벨 NAS 예매 에이전트

시놀로지 Container Manager용입니다. 잔여석 리포터(`reporters/nas`)와 **다른 컨테이너**입니다.

하는 일: 베셀 잡 큐에서 CGV 잡 하나를 가져가 좌석을 누르고, 결제 화면에서 멈춥니다.
안 하는 일: 결제 버튼 클릭, 비밀번호 입력, 캡차 우회.

423과 225는 둘 다 Intel 이라 같은 이미지를 씁니다. **클릭은 한 대만** `AGENT_ENABLED=1` 로 흉니다. 나머지 대는 0.

CGV 화면 선택은 PC 에이전트와 같이 아직 실제 예매로 검증되지 않았습니다. 메가박스 잡은 받으면 실패로 되돌립니다.

## 올리는 법

저장소의 `agent` 폴더를 NAS에 둡니다. Container Manager 프로젝트 경로는 `agent/nas` 입니다.

1. `config.example.env` 를 `config.env` 로 복사하고 토큰을 넣습니다. 토큰은 베셀 `NAS_WORKER_TOKEN` 과 같습니다.
2. 클릭할 한 대만 `AGENT_ENABLED=1`, `WORKER_NAME=nas423` 또는 `nas225`.
3. 프로젝트 빌드. 빌드 컨텍스트는 위의 `agent` 폴더입니다.
4. 로그인이 필요하면 `AGENT_MODE=login` 으로 한 번 재시작합니다. 브라우저에서 `http://나스IP:6080/vnc.html` 을 열고 CGV에 직접 로그인합니다. 비밀번호는 에이전트가 안 칩니다. 세션이 저장되면 `AGENT_MODE=poll` 로 돌립니다.
5. 결제할 때도 같은 noVNC 화면에서 직접 냅니다. 폰으로 결제 URL을 열지 마세요. 자리는 그 브라우저 안에만 유지됩니다.

리포터 컨테이너는 그대로 둡니다. 이 컨테이너가 잔여석을 긁지 않습니다.

RAM이 2GB인 225는 크롬과 리포터를 같이 올리면 부족할 수 있습니다. 클릭은 여유가 있는 한 대로 두세요.
