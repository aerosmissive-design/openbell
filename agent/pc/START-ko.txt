OpenBell PC Agent - 시작 안내
================================

1. 1-install.cmd 더블클릭
2. config.env 편집 (또는 5-open-config.cmd 로 메모장 열기)
     BOOKING_MOVIE=영화명
     BOOKING_DATE=2026-09-20
     BOOKING_SHOWTIME=20:10
     BOOKING_SEAT_COUNT=2
   선택: BOOKING_URL 이 회차 키(scnsNo) 없어도 제목/날짜/시간 클릭으로 진행. 결제 URL은 거부.
3. 선택: 4-save-login.cmd
   CGV에 직접 로그인한 뒤, 검은 창에서 Enter
4. 선택: 3-doctor.cmd
5. 2-run.cmd 더블클릭
   토큰 없음 = 결과 B (dry-run)
   토큰 있음 = 결과 A
   브라우저는 열린 채로 유지됩니다. 결제는 직접 누르세요.
   에이전트는 결제를 클릭하지 않습니다. CAPTCHA를 우회하지 않습니다.
