# 오픈벨 PC 도우미 — 더블클릭 하나

## Windows (업무 최소)

### 처음 한 번만
1. https://nodejs.org → **LTS** 설치
2. 깃허브 openbell **ZIP** 받아 압축 해제
3. 베셀에 `NAS_WORKER_TOKEN` 넣고 **Redeploy**
4. `pc\오픈벨도우미.bat` 더블클릭
   - 주소 / 토큰 / 텔레그램 입력 (토큰 = 베셀과 동일)
   - 로그인 할거냐 → **Y** 하면 CGV·메가박스 창에서 로그인 후 Enter

### 평소
- `pc\오픈벨도우미.bat` **더블클릭** → 바로 실행
- 끄기: 창 닫기

설정 초기화: `pc\.env` 삭제 후 다시 실행.
