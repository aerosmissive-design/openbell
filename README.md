# 오픈벨 (Openbell) v3.2

CGV·메가박스 특별관 예매가 열리거나, 별표한 회차의 잔여석이 변하면 메일·텔레그램·카톡·X로 알려 주는 웹앱입니다.

웹: https://openbell.grok.me  
저장소: https://github.com/aerosmissive-design/openbell

## v3.2에서 달라진 점

- 그록 서버와 구글 스크립트가 둘 다 알림을 보냅니다. 15분 과도기는 없습니다.
- 설정에 X로 올리기(@aerosmissive2)가 있습니다. X API 크레딧이 있어야 글이 올라갑니다.
- 감시 탭과 알림에 몇 회인지가 붙습니다. 잔여석 새로고침은 회차마다 따로 알려 줍니다.
- 설정 순서는 계정·스크립트, 감시 극장, 알림 설정, 배경입니다.

## 쓰는 법

1. 구글 계정으로 로그인합니다.
2. 감시 탭에서 영화 포스터를 눌러 알림을 켜고, 극장 제목·특별관을 고릅니다.
3. 설정에서 메일·텔레그램·카톡을 켭니다. X는 유료 API가 있을 때만 켭니다.
4. 구글 스크립트는 복사 후 붙여넣고 설치하면 됩니다.

## 스택

TanStack Start, React 19, Tailwind v4, Neon/PGLite, Better Auth.
