# 오픈벨 (Openbell) v3

CGV·메가박스 특별관 예매가 열리거나, 별표한 회차의 잔여석이 변하면 메일·텔레그램·카톡으로 알려 주는 웹앱입니다.

웹: https://openbell.grok.me  
저장소: https://github.com/aerosmissive-design/openbell

## v3에서 달라진 점

- 감시·설정에서 극장 제목을 누르면 그 극장 특별관이 전부 켜지거나 꺼집니다.
- 켠 특별관만 알림이 갑니다.
- 그록 서버가 메인 알림, 구글 스크립트는 예비입니다. 그록이 멈추면 스크립트가 이어 갑니다.
- 극장 새로고침은 시간표와 잔여석을 같이 다시 받습니다.

## 쓰는 법

1. 구글 계정으로 로그인합니다.
2. 감시 탭에서 영화 포스터를 눌러 알림을 켜고, 극장 제목·특별관을 고릅니다.
3. 설정에서 메일·텔레그램·카톡을 켭니다.
4. 구글 스크립트는 예비용입니다. 복사 후 붙여넣고 설치하면 됩니다.

## 스택

TanStack Start, React 19, Tailwind v4, Neon/PGLite, Better Auth.
