# 오픈벨 (Openbell) v3.9.20

CGV·메가박스 특별관 예매가 열리거나, 별표한 회차의 잔여석이 변하면 메일·텔레그램·카톡으로 알려 주는 웹앱입니다. 예매를 누르면 좌석을 찍고 결제 화면까지만 가고, 결제는 하지 않습니다.

웹: https://openbell.grok.me · Vercel: https://openbell-fawn.vercel.app  
저장소: https://github.com/aerosmissive-design/openbell

베셀 서버가 알림을 보냅니다. 구글스크립트는 예비이며, 없어도 극장·잔여석 조회는 돌아갑니다.

## v3.9.20에서 달라진 점

- 이 극장에 아직 없는 영화는 다른 극장 회차를 6건만 자르지 않고 전부 보여 줍니다.
- 「외 N건 · 해당 극장 카드를 펼치세요」는 빼었습니다.

## v3.9.18에서 달라진 점

- 알림은 그대로입니다.
- 예매를 누르면 좌석 홀드가 열립니다. 추천 구역을 보고 극장에서 좌석을 찍은 뒤, 결제 화면까지만 갑니다.
- 결제는 오픈벨이 하지 않습니다. 홀드 시간이 끝나기 전에 극장에서 직접 결제하세요.
- 설정에서 인원·선호 구역·홀드 시간·알림 때 좌석 화면 열기를 고를 수 있습니다.

## v3.9.17에서 달라진 점

- 알림 경로의 ‘깃허브 깨움’을 ‘깨움’으로 바꾸었습니다.
- 깨움 칸에 깃허브 크론인지 외부 크론(구글스크립트)인지 표시합니다.
- 구글스크립트는 주기마다 베셀 `/api/watch-tick`을 깨웁니다.

## v3.9.16에서 달라진 점

- 구글스크립트 없이도 극장 시간표와 잔여석이 돌아갑니다.
- 용산 시간표는 네이버가 비면 용아맥 채널을 24시간 감시 안전망으로 씁니다. 영등포는 네이버 + 우회조회입니다.
- CGV 잔여석 우회조회가 15분 넘게 비면 설정에 경고를 띄우고, 메일이 켜져 있으면 알려 줍니다.

## v3.9.14에서 달라진 점

- 잔여석은 극장 공홈을 먼저 조회하고, 막히면 우회·구글스크립트(예비)로 붙입니다.
- 구글스크립트 주소가 있어도 메가박스 공홈 잔여석을 건너뛰지 않습니다.

## v3.9.11에서 달라진 점

- 1·5·10분 주기는 구글스크립트(예비) 칸으로 옮겼습니다.
- 구글스크립트(예비)는 기본 접힘입니다.
- 알림 경로·설명에서 그록을 빼고, 베셀 + 구글스크립트(예비)만 보여 줍니다.
- X로 올리기를 껐습니다.

## 쓰는 법

1. 구글 계정으로 로그인합니다.
2. 감시 탭에서 영화 포스터를 눌러 알림을 켜고, 극장 제목·특별관을 고릅니다.
3. 설정에서 메일·텔레그램·카톡을 켭니다.
4. 예매(홀드)를 누르면 좌석을 찍고 결제 화면까지만 갑니다. 결제는 직접 합니다.
5. 구글스크립트(예비)는 베셀 서버에 문제가 있을 때도 알림을 받고 싶을 때만 켭니다.

## 스택

TanStack Start, React 19, Tailwind v4, Neon/PGLite, Better Auth.
