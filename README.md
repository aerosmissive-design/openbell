## v3.9.70에서 달라진 점

- 알림 테스트는 용산·영등포·코엑스·남양주에 **극장마다 메일/카톡/텔레그램을 한 통씩** 보냅니다. 한 통에 4건을 묶지 않습니다.
- 각 통에 그 극장 랜덤 회차와 「바로 예매」가 들어갑니다. 구글스크립트가 제목을 「오픈벨」로만 보내던 것도 고쳤습니다.
