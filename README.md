# 오픈벨 (Openbell) v3.9.58

CGV·메가박스 특별관 예매 오픈·잔여석 알림 웹앱입니다.

웹: https://openbell-fawn.vercel.app  
전광판: https://openbell-fawn.vercel.app/board
저장소: https://github.com/aerosmissive-design/openbell

실용 개선 작업 기준 버전입니다. 기존 PC/NAS 리포터 구조는 유지합니다.

## v3.9.58에서 달라진 점

- 네이버 시간표를 스캔에 다시 연결했습니다. fast 조회에서도 코엑스·용산 시간표가 먼저 뜹니다.
- 시간표가 있는데도 "못 가져왔습니다" 경고가 뜨던 문제를 막았습니다.
- 메가박스 공홈 잔여석에 출처·조회시각을 붙여, 설정 탭 빨간 시각과 연결했습니다.
- 잔여석 오버레이를 저장해서 화면을 나갔다 와도 바로 비지 않습니다.
- KT 정밀 예매 URL(scnsNo+scnSseq)이 알림·테스트 메일까지 가도록 회차 병합을 고쳤습니다.

## v3.9.51에서 달라진 점

- 텔레그램 알림이 HTML로 보이도록 고쳤습니다. `&` 같은 이스케이프와 `<b>` 태그가 그대로 나오지 않습니다.
- 바로 예매는 클릭 가능한 버튼으로 붙습니다.

## v3.9.50에서 달라진 점

- 포스터를 눌러 알림을 켜도 이미 열린 회차는 신규 오픈으로 보내지 않습니다.
- 웹 알림이 떠도 알림 탭으로 자동 이동하지 않습니다. 배너를 누르면 알림 탭으로 갑니다.
