# 오픈벨 (Openbell) v2.1

CGV·메가박스 특별관 예매가 열리거나, 별표한 회차의 잔여석이 변하면 메일·텔레그램·카톡으로 알려 주는 웹앱입니다.

웹: https://openbell.grok.me

## 쓰는 법

1. 구글 계정으로 로그인합니다.
2. 감시 탭에서 영화 포스터를 눌러 알림 설정, 극장을 펼쳐 특별관을 고릅니다.
3. 설정에서 메일·텔레그램·카톡을 켭니다.
4. 로그아웃해도 알림은 유지됩니다. 끄려면 다시 로그인해 채널 토글을 끄세요.
5. 잔여석은 2분마다 자동 갱신됩니다. 극장 옆 새로고침은 바로 보고 싶을 때 씁니다.

## 스택

TanStack Start, React 19, Tailwind v4, Neon/PGLite, Better Auth.
