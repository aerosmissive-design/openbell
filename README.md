## v3.9.78에서 달라진 점

- 감시 회차 카드는 출처를 항상 적습니다. 없으면 「없음」.
- 「N.NN일 HH:MM 기준」은 버그입니다. 우회경로가 베셀에 도착한 조회시각 + 출처만 쓰니다.
- 현재 시계를 seatCheckedAt에 찍지 않습니다.
- 설정 출처 표에 CGV우회·GAS·용아맥채널 칸을 추가했습니다. 기존 UI는 지시 없이 빼지 않습니다.

## v3.9.77에서 달라진 점

- 감시 회차 카드는 잔여석 출처를 항상 적습니다. 없으면 「잔여석 출처 없음」.
- 「기준」시각은 지금 시계가 아닙니다. 우회경로가 베셀에 들어온 조회시각입니다.
- 설정 출처 표 등 기존 UI는 지시 없이 빼지 않습니다.

## v3.9.76에서 달라진 점

- 설정 → 감시 극장 아래에 「상영시간 및 잔여석 현황 출처」 접기/펼치기 표를 다시 붙입니다.
- 표 열은 공홈 · G_PC · G_NAS · KT 우회 · 네이버입니다. 시각이 없으면 「없음」입니다.
